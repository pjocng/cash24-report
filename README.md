# Cash24 Regulatory and Build Report (interactive)

Interactive web version of the *Cash24 Secured P2P Lending Platform: Regulatory and Build Report* by Pjoc Nigeria Limited.

It is a single static file (`index.html`) with no build step and no external dependencies.

## Host it on GitHub Pages

1. Create a new repository on GitHub (for example `cash24-report`).
2. Upload `index.html`, `.nojekyll` and `README.md` to the repository root.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
5. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Note

The repository and the Pages site are public by default on a free account. The report names a client, so use a private repository (needs a paid GitHub plan for Pages) or remove anything confidential before publishing.
